# Saymivo · 让口播剪辑少一点重复劳动

你录好一段视频，Saymivo 帮你整理字幕、剪掉多余停顿、安排重点文字和讲解画面。**先让它帮忙，再由你检查和修改，最后导出 MP4。**

它运行在你的电脑上，适合做中文口播、课程讲解和操作演示。目前主要在 Apple Silicon Mac 上验证。

[English](README.en.md) · [安装与排错](docs/setup.md) · [实际演示](docs/demo.md) · [开发原理](docs/architecture.md) · [参与贡献](CONTRIBUTING.md)

## 它能帮我做什么？

<p align="center">
  <img src="docs/assets/cartoon-features.png" alt="卡通讲解：你提供原片，工作台整理字幕与画面，你检查后导出视频" width="880" />
</p>

比如，你录了一段讲解视频，里面有几次停顿、几个专业名词，还想穿插一张讲义和一段屏幕操作。你可以把素材交给 Saymivo，先得到一个可编辑的版本，再逐段调整。

| 你遇到的事 | Saymivo 可以帮忙 | 你仍然需要做什么 |
|---|---|---|
| 一句句打字幕很费时间 | 在本机听取录音，生成中文字幕 | 检查人名、数字、专业词有没有听错 |
| 说话中间停了太久 | 找出停顿，生成剪辑切点 | 听一遍，确认没有剪掉字音或自然换气 |
| 从头到尾只有一张脸 | 加重点字、讲义、录屏和人物小窗 | 提供相关图片/录屏，检查画面和讲解是否对应 |
| 自动做完后还想改 | 调字幕、改分镜、替换素材、调整镜头 | 按自己的表达习惯决定最后效果 |
| 想继续编辑或交付成片 | 保存工程，导出 MP4 | 留好原素材，检查导出视频 |

**不需要为了试用先申请 AI 密钥。** 基本字幕与术语整理可以在本机完成；Gemini 校对和 Pexels 素材搜索是可选功能。

## 它是怎么工作的？

<p align="center">
  <img src="docs/assets/cartoon-how-it-works.png" alt="卡通原理图：读取原声，生成带时间的字幕，按规则剪辑和排画面，人工检查后导出" width="880" />
</p>

可以把它理解成一张“记得原片时间的剪辑清单”：

1. **先听：** 语音识别工具 faster-whisper 把声音转成文字，并记录文字大致在原片的什么时间出现。
2. **再整理：** 用术语词库纠正常见写法，找出可以裁掉的停顿，按规则安排重点字和讲解画面。
3. **让你修改：** 工程保存的是素材路径、剪切位置、字幕和画面安排。改一句字幕或一处镜头，不必重新识别整段视频。
4. **最后合成：** 预览和导出使用 Remotion 视频组件；FFmpeg 等工具负责素材处理。你检查满意后，再导出 MP4。

自动安排主要依靠已有规则与模板，**不能代替你判断内容是否正确、剪辑是否自然、画面是否好看**。想看代码如何配合，可以读 [架构文档](docs/architecture.md)。

## 第一次怎么用？

<p align="center">
  <img src="docs/assets/cartoon-get-started.png" alt="卡通使用流程：启动工作台，打开演示或导入自己的视频，预览修改，保存并导出" width="880" />
</p>

### 1. 安装并打开工作台

目前建议用 **Apple Silicon Mac**。先准备 Node.js 22+、npm、Python 3.10–3.12（推荐 3.12）和 FFmpeg / ffprobe。还没有这些工具的话，先看 [安装与常见问题](docs/setup.md)。

在终端执行：

```sh
git clone https://github.com/Olandooooes/saymivo.git
cd saymivo
npm run setup
npm start
```

打开 <http://127.0.0.1:5188/>。以后也可以双击项目里的 `启动 Saymivo.command`。使用时保持终端窗口运行。

> `npm run setup` 会安装项目依赖并创建本地 Python 环境；完整 FFmpeg / ffprobe 需要预先安装。第一次下载依赖、识别模型或渲染浏览器可能花一些时间。

### 2. 先打开演示，熟悉界面

点击首页的 **「演示工程」** 或 **「打开演示工程」**。不需要自己的视频，也不需要下载语音模型。

你会看到一段 18 秒的无真人图形演示。试着播放、改一句字幕、调整镜头，感受“自动整理后还能手工改”的流程。[查看演示说明](docs/demo.md)。

### 3. 再处理自己的视频

1. 选择模板、横屏或竖屏，以及字幕校对方式。
2. 拖入 MP4 / MOV / WebM 视频，默认开始自动剪辑。第一次识别会下载多语言 `small` 模型。
3. 完成后播放预览：先核对字幕和剪口，再调整重点字、讲义、录屏和人物位置。
4. 保存工程，导出并检查 MP4。以后继续编辑时，保留工程和对应原素材。

**先用一小段素材试跑，再处理长视频**，更容易发现安装或布局问题。速度取决于电脑、视频长度和选用的功能。

## 我的素材会发到哪里？

- **基本本地流程：** 原片、字幕、工程和导出保存在你的电脑上，主要位于 `public/`；后台任务、个人词库和校对历史也保存在本地，并已被 Git 忽略。
- **主动开启云端功能时：** Gemini 校对会发送字幕文字和术语信息；部分 AI 编排/分析还可能发送选定文本或画面。Pexels 搜索会访问外部服务。启用前请查看 [配置示例](.env.example)。
- **运行环境：** 这是可信本机工具，不是可直接部署到公网的多人服务。不要公开素材目录或转发服务端口。

## 先了解这些限制

自动字幕会听错，自动剪口和版式也可能不合适；重要内容请对照原声检查。人物默认位置不是自动人脸跟踪，专业讲义和录屏也需要你提供。字幕内部词时间可能是估计，整句校时不等于逐词验证。

Windows / Linux 安装、不同拍摄背景和长片稳定性仍需要更多验证。这里的卡通图用于解释功能和流程，**不是软件截图，也不是自动剪辑质量的证明**。实际组件画面放在 [演示页](docs/demo.md)，避免一张很长的竖图占满首页。

## 想改进它？

React / TypeScript 写界面，Node.js 管理本地任务，Python 做语音处理，Remotion 预览与导出。

```sh
npm ci
npm run check
```

这会运行类型检查、单元测试和前端构建，不会下载模型或处理私人视频。欢迎提交可复现的问题、无私人内容的合成示例、安装反馈和小范围修复。
