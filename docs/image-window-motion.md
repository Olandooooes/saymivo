# 图片窗口自动匹配与复用

右侧「动效」顶部的「图片窗口 · 自动匹配」提供小段起点、5–60秒范围、放大倍率与换图时长。修改参数后重新匹配即可更新，应用使用既有工程撤销机制；播放样段到末尾自动暂停。未请求导出时只用实时播放器。

素材从当前工程图片库选择。导入图片后在「素材匹配词」登记它对应的名称或主题；可用多张同组图片。匹配器只根据字幕明确出现的登记词选择资料，不上传素材，不读取文件名来猜统计内容，也不自动造图。未命中或没有足够阅读时间时保留口播。图片匹配词与工程一起保存，可撤销；新项目需要自己的相应素材。

`imageWindowMedia`生成归一化窗口关键帧和各张图片的独立镜头，`SceneMedia`共用同一渲染路径：外层窗口先放大、保持阅读、缩回；内层相机对当前图片缩放和平移；切换时新图逐渐覆盖仍不透明的旧图，避免叠化中露出背景。换图后的镜头从新图自身零点开始，外层窗口相位持续，不把前图的裁切坐标套到后图。无sequence字段的旧图片/录屏继续走原分支。

默认每段最多三张，每张保留至少约2.8秒实际阅读时间，换图对齐真实字幕页起点，场景不跨实际剪口。以`clipInstanceId`绑定精确片段实例；同源重放不自动重复一段资料。编排已有人工分镜时保留原分镜；再次匹配只替换对应的自动窗口段。保存前的异步图片解码检查工程身份与数据快照，发生变化则拒绝旧结果。

应用将所选工程切换为资料主画面模式并保留右下人物圆窗，字幕和原声不改。它是基于登记词的规则匹配，不等于整段语义理解；人物动作、具体阅读焦点、不同画幅的实际构图仍需播放确认。剪口、速度、字幕或图片改变后重新匹配。

回归：image-window-plan、image-window-render、media-window-motion及完整`npm run check`。覆盖不同合成话题、无资料/截断拒绝、重复图片去重、英文词界、慢快阅读预算、剪口实例、换图前后真实组件层数和时钟。实际原片的两种内容段、参数更新/撤销、重开与原始数据比较留在本机inspection/image-window-auto-20261024/；合成测试不替代动态观感认可。

图片解码后还检查最低480×200的实际分辨率，避免把素材缩略图放大充当资料页。除同一原片的两个主题段之外，另用不同原始视频中的工作台目标段执行同一入口：素材为已有工作台录屏的原尺寸截图和已有交付讲解图，分别明确登记；没有把讲解图冒充实测截图。对应的原声/字幕/剪口与生成前比较保持一致。
