# 本地字幕上下文与原声复核

正式「生成中文字幕」和自动剪辑的字幕校对阶段共用 `proofreadSourceCaptions`；后者在选关闭校对时跳过，不把同一工作重复运行两遍。生成器保存 `captions.raw.json` 与校对记录，原识别缓存不覆盖。明确选择云端语义模式仍沿用原有授权边界；本地模式不发送文字或音频。

流程先按词库和有限领域搭配提出疑点，再对原片对应时间窗用本地medium重识别；英文全称介绍采用完整相邻窗口，另加英文语言识别作辅助观察。尚未得到证据的同音词/缩写疑点可用已安装small再读一次。没有模型、没有原片时钟身份或证据不足时保留原文。未知缩写不自动扩写成百科全称；明确介绍的英文全称只统一已识别文字的大小写。

音频证据需与字幕的原片SHA一致，并在原词相邻250ms内读到目标词、相同带声调的中文读音，或保留声调与韵母的限定 zh/ch 识别混淆。同音字用有限上下文选字，声学证据无法独立证明字形；铁路复线、截止时限等冲突语境排除。全文反复出现的缩写只用于提出漏字候选，补字仍需局部音频确认。词库歧义、数字、否定、跨度过大等保护继续生效。规则门槛不是统计正确率。

音频观察缓存按原片SHA、模型字节SHA、复核脚本SHA、原片窗口、语言和音频时钟版本隔离，缓存原声观察，不缓存人工取舍。纠错不改变原词外边界，不按新增字符数推算发音时间；长度改变时保留整个原词组范围作为显示单元。字幕校对不是强制对齐，不应用校对后的显示词时间判断音频剪口。

中文领域搭配词表是有限覆盖，未知人名、品牌或新术语可能仍需用户词库。大小写规范与拼写核验分开记录；局部重识别也可能复现原错误。不把模型识别、测试或文件可播放当作完整人耳听审。

回归：`node --test tests/proofread*.test.mjs` 与 `npm run check`。真实原片观察和比较结果放在被忽略的 `inspection/` 下，不进入公共样例。

编辑器已有字幕时，按钮明确显示「重新生成并校对字幕」。只替换本轮确实返回字幕的来源，空结果或失败来源保留旧字幕；工程/片段/字幕在分析期间变化时不覆盖当前编辑。整批应用进入一次撤销。真实操作验证需与代码回归分别记录。
