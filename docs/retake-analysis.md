# 口播精剪：候选、证据与可撤销应用

编辑器中的“口播精剪”对当前片段的原片时钟做分析，返回剪辑计划；后端不修改工程、原视频或已有人工决定。编辑器验证计划与当前工程快照一致后，一批操作进入一次撤销记录。待复核候选需要使用者试听并明确选择。

API 未指定模式时使用完全本地的 `local` 模式。现有 `.models/whisper-small` 做重叠窗口识别，`.models/whisper-medium` 对候选的前、后版本分别做独立窄窗识别。模型缺失时报告错误，不自动下载或切换云端。与源文件 SHA、识别内容 SHA、source-zero 时钟一致的原始 ASR 缓存可作为基线；人工改写字幕、工程内容和 `source-edit-decisions` 不参与识别。

`local` 候选生成使用带原始词时间的字符序列对齐，比较附近重说的前缀及改词。字符只用于文本比较；一个词有几个字也保留同一原词时间，不制造字内切点。算法会漏掉短语、近义表达或被 ASR 合并的重录，不能称为通用语义判断。

本地自动批准必须同时满足：

- 前版本在未完成词组处停止，后版本依原顺序覆盖前版本全部文字并继续完成分句；完整重复默认待复核，防止删除刻意强调。
- 前后版本之间没有其他转写语音；VAD 也没有发现前版本范围之外的待删语音。
- 数字、否定词和英文专名的保护检查没有差异。
- 独立窄窗 ASR 分别确认两遍完整文字。
- 10ms RMS 低能量间隙和原片词时间共同确认剪口；删除范围不覆盖保留版本，且均在快照原片范围内。

不满足条件时原声仍保留，给出原因与前后版本试听范围。相似度及规则分数不是统计正确率。A→B→C 连续重录只会沿已经批准、有独立证据的链统一保留 C；冲突取舍转为待复核。

## Codex 语义取舍

正式 `codex` provider 及现有精剪窗口接线已实现，服务端开关在新安装中默认关闭，通过本机验证后显式开放。安装 CLI 或本地模型不会自动启用；只有 `SAYMIVO_CODEX_RETAKES_ENABLED=1` 且能力检查通过时，窗口才允许选择“本地识别 + Codex”，就绪时窗口默认选中该方式，仍需使用者勾选文字同意。能力检查核验本地环境、模型及 CLI 可执行文件，不保证账户登录或实际任务一定成功。

使用者选择该模式后，还需明确勾选允许发送转写文字；请求必须带 `mode: "codex"` 和 `allowCloudText: true`。未开放或未同意时，服务端在创建推理任务前拒绝，不悄悄替换 provider。Codex 流程不调用 Gemini；视频、音频及本地路径不发送给 Codex。原有 Gemini API 分支仍只接受显式 `mode: "gemini"`、文字同意及配置好的 key，当前窗口不提供该选项。

`analyze-codex-retakes.mjs` 直接处理当前工程的有序片段快照，不调用短段实验来代替正式分析：

- 按同一原片读取本地 Qwen3-ASR 转写、Qwen 强制对齐及 source-zero 音频凭证；每份证据绑定原片 SHA、模型字节和识别脚本版本，源文件变化则结果作废。
- 将当前仍保留的观测词按片段实例及时间线顺序组成上下文，保留各片段的变速映射；Codex 仅返回连续删除词编号、替代词编号及原因，不能编造时间或改写原话。分窗有重叠上下文，决定只收一次。
- 独立本地 Whisper medium 以重叠长窗及 VAD 分出的语音短窗重新观察整片，各词流单独交给 Codex 召回漏删；不同识别的词编号不拼接。Qwen 主识别候选由 Whisper 自由重读，Whisper 补充候选反过来由 Qwen 自由重读；给定文字的强制对齐不冒充独立识别。
- 独立识别的词时间可能跨过长静音。对各实际自由识别窗口的全部文字重新作本地对齐，保留直接观测到的整体词组时间，不按字均分；零时长、错配和重叠继续保留为未决。原始失败时钟和收据单独保留，新时钟只替代时间观测，不成为第二份自由 ASR 或语义投票。原始短窗出现但 canonical 词流遗漏的纯语气词另作独立上下文召回，仍经过全部删除门。
- 边界 v2 选取测量静音区内的复核窗口，将实际窗口内全部观测词提供给本地对齐器。零时长词只合并相邻等时观测，不插值制造字内剪口；主识别和独立对齐的保留词范围取并集，核验两侧相邻词及替代版本完整保留。
- 自由重读将两遍录制分别括在最近的真实静音边界内，比较每个实际音频窗口的全部文字。不能把两遍送入同一识别窗，让识别器折叠重复后再误判确认失败；缺少分离静音、窗口含另一遍或未决语音时继续待复核。较宽的相邻词时间复核仍由边界 v2 独立完成。
- 数字、否定、英文专名变化，缺失静音缝、上下文或独立确认，以及取舍相互冲突时，均不能自动批准。孤立零时长或重叠时间观测成为保护标记，其余有有效时钟的内容继续分析，不插值补时间，也不再让一处异常中断整片。
- 保护词按完整值及顺序定位，结合原表达在保留版中的完成位置检查新增否定，不按相同汉字长度截断较长表达。中文扩写后移的同一专名不会因此误报；正负号、小数、百分比、真实专名变化和新增否定继续阻止自动批准。繁简差异只用绑定原文的本地比较副本核对。
- 无意义语气词有单独候选类型，替代表达明确为空。回答、强调、句末情绪、连读及有实际词义的同音词保持待复核；自动删除要求两个不同本地识别器的自由观察确认同类犹豫音并保护两侧词，任何有效词侵入删除范围都会阻止自动批准。
- 剪口只能在同一已测静音区内收尾，同时保护主识别、全部当前有效的独立识别时钟、未决词和无词归属的 VAD 声音。不得跨过新的声音区；短尾段不能因美化剪口而吞掉有效词。
- 已验证覆盖的 VAD 仍可能在真实静音内维持语音状态。只有整段残余及保护余量被同一静音交集、完整相邻词与来源收据共同括界，才可解除这一条粗状态反证；显式未决声音继续保护。两侧收尾各自使用全部原保护范围检查，增长区触碰该例外保护带的一侧保持不动，整段新剪口重新核验。既有批准结果若改变几何范围，其旧识别与边界收据失效，必须重新验证。
- 各轮取舍按精确实例和原片时间合并，只合并各自已验证的结果。待复核证据不能互相补齐成自动批准；保留版本互删的冲突一次性撤销双方批准。随后自动应用计划的剩余时间线再次交给 Codex，复查剪后仍保留的内容，不读取人工 EDL。

替代版本可以位于待删版本之前，不能机械保留最后一遍。同源的待删和保留表达可以分别属于当前快照中的不同片段实例，应用只裁切指定待删实例。同一次表达自身跨多个去停顿片段时，按各精确实例分成 `removeParts/retainParts`：源时间必须单调、源词连续，每个新剪口及每个保留片段边缘均独立复核。跨原片、遗漏源词、时间回绕、半词及相邻不完整上下文、替代版本被另一取舍删除或未知实例均保留，不按文件名猜测归属。`source-boundary-v2`、独立 ASR 及声学证据全部通过才进入自动批准；程序分数不是统计准确率。

模型任务运行于独立目录，使用结构化输出，配置禁用 shell、应用、插件、子代理、技能搜索、网页及看图工具；输入转写只作为不可信数据。取消、超时或正常关闭服务会停止本次子进程组；等待实际退出期间保持忙碌，必要时对本次组升级终止，不触碰其他应用。作业结果仍经过同一工程快照、原片身份及替代版本检查，显式应用整批取舍只产生一次撤销；不会由后端改写保存工程。

原片时钟、字幕、配图和旧分镜的片段投影沿用既有应用层。跨片段及保留较早版本已有合成回归；不把这些测试冒充真实操作和听感验收。

旧字幕时间可能越过新识别的剪口。应用时仅在精确删除实例附近完整、最近唯一匹配删除文字，才清理整组旧字幕词，支持跨字幕；不完整或歧义匹配保留并提示。完全落在保留片段中的字幕沿用全部词及其时间，包括零时长首词，避免在后面剪另一句时损坏前面的字幕。整批撤销恢复原有字幕数据。

旧字幕也可能把两遍重录合成一次。删除前一遍时，保留版的前缀字幕可能随之丢失。已通过全部原声及边界验证的候选会附带保留版的实际原词时间；只有现有字幕是该完整文字的非空精确后缀，且缺失前缀在本次删除的原字幕词中唯一出现，才局部恢复。数字、否定、专名、人工校正、显式复核时间或来源不一致时不猜改；不把字符均分成时间，也不重建全片。恢复与剪辑属于同一撤销事务。

## 接口与证据

接口：

- `GET /api/retakes/capabilities`：返回 `local.ready` 及 `codex.ready/enabled/dependenciesReady/reason`；默认关闭 Codex 开放开关。
- `POST /api/retakes/analyze`：`clips` 为有序快照，包含 `id/src/inSec/outSec/speed/sourceDurationSec`，默认 `mode: "local"`、`policy: "conservative"`；Codex 还要求上述能力门及文字同意。返回 `202 {jobId}`。
- `GET /api/retakes/:id`：`progress` 为 0–1；完成结果含 `snapshot/sources/candidates/warnings`。`sources` 含源 SHA 和完整原片音频时钟。
- `POST /api/retakes/:id/audit`：只接受本次自动应用前后工程。服务端重放已保存计划并逐项核对剪后片段，再生成整片无损声音、每个新剪口和每个删除部分的前后对照。结果挂在 `GET` 的 `audit` 中；`audit.status: done` 只代表审计产物生成成功，声音数值结论另看 `signalStatus`。
- `GET /api/retakes/:id/audit/files/:auditId/:basename`：只提供本次报告和白名单声音文件，支持 Range；不提供源路径、输入或日志。
- `POST /api/retakes/:id/cancel`：取消当前本地进程组。已应用取舍后的审计取消不会撤销剪辑，界面明确提示仍可撤销。服务重启后未完成任务转为错误，使用者重新发起分析。

作业文件存放在已忽略的 `.auto-jobs/retakes/`。公开测试只用合成文字、时间与临时文件，覆盖桥接新信息误删、保护词、强调重复、字内边界、链冲突、取消、并发、重启、路径与本地不调用云端。

声音报告分别列出内部未决、跨边界未决、实际词跨界和自由识别文字差异；给定文字对齐按每个实际观察窗口独立列出，不拼接为另一份转写。整段繁简比较副本保留原文、原始匹配结果、转换器和字典摘要；数字、小数、正负号、百分比及新增否定继续严格区分。检查区间行数不是已确认削字处数，最终 AAC 文件另行核验。

重复分析可复用 `.auto-jobs/retake-evidence-cache/` 中的原始分段识别、声学观察和独立窄窗识别。缓存键包含完整源 SHA、本地模型字节 SHA、识别引擎版本、音频时钟与分析版本；读入时再次核验 WAV/证据内容。新作业仍验证当前快照、重新生成候选与批准决定，不缓存或复制人工 EDL、最终取舍或其他 UI 作业状态。

整片独立观察另存 `.auto-jobs/codex-independent-evidence/`，缓存绑定原片、音轨、模型、脚本、运行时及窗口参数。遇到同身份活动写入者时可取消地等待，不启动争用进程；读取完整收据后才消费，不把取消等待等同于取消另一个观察任务。

Codex 主识别证据另存 `.auto-jobs/codex-source-evidence/`，指纹同时包含音频辅助脚本、时钟规范、模型配置及本地环境；损坏缓存按未命中处理，中断的 WAV/时钟配对先隔离再重建，收据原子发布。每次作业重建当前保留词流和取舍，不把缓存当作人工剪辑结果。独立任务中保留词编号输入、模型输出凭证、原声确认及边界报告，私人素材及转写不进入公开文档或测试。

## 当前验证范围

当前单素材短段的4个旧空外边界已由 v2 复核取得观测，3处拟剪口通过机器边界门。使用同一裁切及 concat 图的 AAC 编码前审计，709个保留声音窗口检查无失败，51个首尾保留词窗口均通过；1个低能量窗明确未验证。该结果证明已选区间在编码前保留了相应观测声音，不证明模型没有漏掉重录或误判意图。

独立 Chrome 的真实工作台已从按钮对去停顿后的五片段短段重新运行正式 provider：3处候选均通过并自动应用，对应字幕完整清理。首次真实循环发现的残字与零时长首词丢失已修复后另跑新作业；最后循环一次撤销恢复全部片段及字幕数据，保存后逐项深比较一致，原有用户工程保持不变。更新代码不自动重剪旧工程，需要从现有入口重新分析。

收紧后的七类合成语义回归全部通过。一次先前复跑曾出现共同前缀误建议，失败证据仍保留，该提案同时被句内无合法静音的批准门挡住；这些有限样例不证明一般准确率。上述短段阶段的项目检查通过967项测试、类型检查及生产构建；不代表后续修改已通过。回归过程和未覆盖范围见[案例](experience/2026-10-24-codex-retakes.md)。

实际 AAC 文件仍有两处内部短窗未满足严格波形阈值，无剪辑中性转码在同源窗口也出现差异。保留独立失败报告，不把差异改写为“精确一致”，不根据中性对照降低删除或削字检查门槛。原片身份、无损审计及编码差异的工具见[短段实验](codex-retake-benchmark.md)。

新增的整片独立召回、语气词验证与剪后复扫已接入正式流程；其真实整片结果与旧短段结果分开记录。多素材泛化、整条视频的语义误删／漏删及自然气口听感仍需验证。没有完成或宣称人耳听审通过；功能开放状态由本机显式开关决定。

整片复测中，VAD 的完整语音段尾部也可能略长于已观察词尾。重新括界只能针对包含本次已选删除词的同一个已验证语音段：所有时钟的实际词须属于该次删除，显式未知声音、保留词及其保护余量仍完整生效。来源收据在本次进程重新校验；序列化的 `coverageVerified` 或旧候选证据不能授权。调整只产生新提案，随后重新做全部边界与独立自由识别，不复用旧批准。

## 跨停顿词时间修复

分段ASR也可能把相邻两遍合成一个跨静音的长词。比较候选前，`repair`阶段检查异常长词与真实低能量间隙的交集，将相关语音段交给独立本地medium识别；保留模型观测到的原片词时间，不按字均分。两端均被独立读到的旧词才被替换；单端观测不能随意删词。同词的额外伸长部分必须同时有低能量和无独立语音的证据，才能去掉旧伸长锚点；静音幻觉尾词也要求独立观测、至少95%低能量覆盖且语音覆盖不超过80ms。空识别不删除已有语音。

独立重读缓存只存原片身份、模型字节与音频时钟对应的观察，不存编辑取舍。新作业重新合并证据并生成候选。毫秒取整与浮点窗口边界允许1ms观测容差，避免漏掉恰好落在窗口起点的首音，不改变词时间。

停顿分析启用本地独立识别保护时，合并已验证来源词、工程字幕词和独立修复后的词范围，最后再检查所有受保护词都完整落在保留片段内；不会只选一份时间覆盖另一份。修复重录发现不等于批准删除：完整重复、改词和取舍不确定项目仍保持待复核。

纯合成回归：`python3 tests/speech_repairs_regression.py`；编排回归包括修复后候选能被实际发现、不会凭修复冒充批准；停顿回归包括独立词头保护和末次全词检查。工程默认应用/撤销检查仍使用`npm run check`。真实交付的逐项取舍、全片听审和通用自动化能力分开记录。
