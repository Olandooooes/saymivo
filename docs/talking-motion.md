# 小段口播自动动效

工作台右侧「动效」页提供起点、5–60秒范围和「自动匹配并实时预览」。每次最多三项；匹配后直接进入现有播放器，保存到工程并可撤销，不修改字幕、剪口、音量、人物裁切或原有分镜。没有明确结构时保留口播，不为凑数量添加效果。此入口独立于需要已有分镜节点的旧动效建议页。

自动匹配现在复用已确认的科技靛蓝/思源黑体版本：`TalkingMotionLayer`只负责时钟适配，直接调用原有`StoryboardLayer.SceneTags`，共用字型、下划线、逐行入场与旧论点描边退淡。上一轮黑底卡片渲染已被替换，没有复制一套近似蓝字动画。匹配类别为完整论点强调、明确转折对照、顺序步骤。匹配使用共享字幕分句整理的临时视图，不覆盖字幕；保留原词、限制词和时间，不派生统计数据、截图或新论点。步骤至少两项，只有明确顺序标记才累计展开；转折需要“不是/并非…而是…”两侧原文。普通提及、被剪口截断的字幕和已有词级动效均不自动使用。阅读时间与字量门槛属于启发式，命中不等于语义验收。

每项可播放、移除、调字号、水平/垂直位置、宽度及入场速度。播放本项在结束时暂停。默认前两项左右分置，第三项放在左下侧；目前没有自动人脸避让，不保证所有人物站位和画幅均安全，必须实际预览。沿用旧版蓝字的字号几何与源词时钟，自动按词组分行并限制整体高度，不删内容。新内容的字号、阅读节奏和人物动作仍需实际预览，不能把继承旧动画当成观感自动通过。

配置通过Presentation.talkingMotion保存，包含精确片段ID、源路径、源毫秒和原词快照。渲染投影使用帧舍入后的片段时长、排列与速度；字幕内容、词时间、媒体路径或保留范围不兼容时停止显示该项，面板提示重新匹配。同源重复实例不共享动效。剪口改变后不猜测新归属。

新素材路径：导入视频 → 生成/校对字幕 → 在「动效」中选小段 → 自动匹配 → 播放确认或调参。不会自动跑整条素材。三个组件由MultiClipVideo直接调用，同一渲染器用于实时预览及之后明确请求的导出。

回归：`node --test tests/talking-motion*.test.mjs`，然后`npm run check`。合成测试覆盖不同话题原文、否定保留、步骤时点、不明确/截断拒绝、非叠加、换媒体/改字幕失效、变速重排和实际组件入退场。字体回调合成测试不代替真实像素与动态观感。私人真实工程与截图留在inspection/talking-motion-20261024/，不进入公开样例。

蓝字适配层回归另见 `tests/talking-blue.test.mjs`；实际渲染回归执行原有SceneTags JSX，检查两边确实共用代码、旧论点退淡、未来项未提前出现、颜色、字体与变速下的逐行时钟。原蓝字项目仅增加组件导出，没有改它的JSX和配置。实际口播证据位于inspection/blue-auto-20261024/。
