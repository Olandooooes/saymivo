# 可编辑字幕风格

工作台右侧「样式」中的字幕风格面板提供字体、字号、字重、位置、行距、普通文字/重点词颜色、描边、阴影和半透明底条。三个内置起点为底部白字、半透明底条、醒目粗体；用户可保存当前设置为个人预设。个人预设在当前浏览器localStorage，项目实际使用的样式保存在presentation.captionStyle，随工程、撤销和导出参数走；不会把某条原片作为所有工程的默认。

单条仅存styleOverride差异，其余属性继承全片设置。调整全片预设保留明确例外；可清除例外。启用样式后的预览拖动/缩放修改单条例外，不覆盖旧工程原有位置/缩放，清除例外可恢复继承。旧工程未启用时继续走原渲染分支，不批量改历史项目。

预览与导出共用CaptionTrack解析，保留英文单词的换行保护；底边按字幕估计高度留出空间。它是保守防裁字，不能替代所有字体/多行边缘的实际检查。字体使用本机系统字体及回退；没有上传或下载字体。样式不改变原声、文字、词时间、字幕分句或剪口。字号单位为视频画布像素，播放器缩小时视觉字号同步缩小。

验证分层：一般外观修改先实时预览；涉及渲染或排版边界可导出短段，阶段交付再导出整片。不为每一个参数修改重复导出示例视频。回归：`npm run check`，包括实际渲染分支、旧工程外观、参数边界、实际store的继承与撤销。用户素材截图及真实操作记录留在本机inspection下。

字幕显示统一隐藏当前字幕句尾的逗号、句号、问号、感叹号、分号、冒号、顿号和省略号等，句中标点及成对的收尾引号/括号保留。处理发生在显示词副本，既覆盖普通字幕也覆盖参考样式；不修改原始字幕、词时间或校对记录，视频导出共用该规则。

分句和换行共享词语边界：ICU中文分词、连续英文标识符、已知术语及校对术语表中的专名获得保护；布局额外绑定助词与人物后缀，保留原词高亮时间。分句在真实长停顿、标点和片段边界内，优先按话题、转折和完整短语分页，避免孤立连接词与极短尾页。它仍是有长度/时间限制的语言规则，不等同于完整语义理解，未登记的歧义专名可能需要加入术语表。

已有字幕可点「按意群整理分句 · 可撤销」使用共享规则重排，不重新识别、不导出视频；原词对象与时间保持不变。不同片段、样式、音频时钟及已复核时间是保护边界，带动效的字幕保留。可撤销回到操作前分句。回归入口为 caption-pages、caption-word-groups、caption-reflow 测试；普通/参考渲染器均采用词语保护。
