# P1-v11 补边不镜像人物，同屏不重复字幕

用户看过 v10 的真实帧。景别占比达标。这一轮只改通用画面规则，不改倍率配置，不改粗剪，不渲全片。用户还没接受这一版。

## 改了什么

- 拉远露出的区域只平铺人物旁边的窗帘。肤色列和明显暗于窗帘的列（头发、肩膀、衣服）不拿来镜像。条里残留的肤色或发丝先换成窗帘颜色。源画面边缘如果是人，接缝不再往外抹。补边区里肤色，或暗于窗帘的人物像素，超过 1% 就失败；脸框中心落在补边区也失败。
- 某一帧如果没有干净背景可延伸，这一帧提高缩放或把人物往画面里收，直到补边区没有人。宁可少拉远，也不复制人。`style.json` 里的拉远仍是 0.80×，居中 0.85×，推近仍是 1.08×。
- 同一句文字在一个画面里只出现一次。检查把字幕、标题、大字、卡片和章节条都算进去。大字或卡片正在显示这句时，底部字幕不画。标点不同仍算同一句。
- 落定的字若超出安全区（四边约 4%，且在章节条之上），就缩小或挪回画面内。从画外滑入、滑出的过程仍允许暂时出画。对照的后半句不早于这句开口，并保留到这句说完；下一张卡片若已经在说同一句，前一张提前停。

## 怎么验证

`python3 tools/koubo-port/pipeline/test_autocut.py` 通过。合成目录稿仍是拉远 86.3%、推近 5.0%、小窗 6.7%；91.366 秒时钟上仍是 85.3% / 2.6% / 8.8%。竖条清晰填边比值 1.412，整片模糊仍低于 0.45。窗帘条补边的人物检查为 0；把肤色涂进补边区会失败；整帧都是人时缩放到铺满画面，补边区不再有人。两句对照的后半句 `at` 等于第二句开口，画面保留到这句结束。字幕和大字同句时，隐藏后检查通过；不隐藏则失败。

`npm run check`：1241 项，1235 通过，0 失败，6 跳过，vite build 成功。

## 压缩原片上的复核

没有重跑识别，没有改 VAD，没有改清晰度阈值 0.45，没有改粗剪。草稿重算后占比不变：拉远 90.5%（88.49 秒），推近 4.4%（4.31 秒），小窗 2.0%（2.00 秒），结尾 3.1%。重复检查为空。若强制把字幕也画上，开场那句会和标题撞上，说明检查确实把字幕算进去了。

12.4、样片第一帧、40、42、43.2、49.9 秒的补边人物占比都是 0。清晰度比值都在 0.94 以上。这几帧实际缩放约 0.80–0.81，补边是干净的，没有被迫收成全幅。

- 12.4 秒：大字是问句，底部没有同句字幕，章节条仍是另一句。左缘和顶部是窗帘，没有半张脸，也没有头发。
- 40 秒和 42 秒：只有前半句，后半句还没开口，所以不在画面上。左缘和顶部是窗帘。底部没有同句字幕。
- 43.2 秒：后半句已经开口，整句大字落在画面内，黄字横向大约在 727–1734，没有贴边。底部没有同句字幕。
- 49.9 秒：单句大字落在画面内，没有同句字幕。右侧补边是窗帘。
