- 编辑器「转写校对」可以改词库（`正确写法｜识别错写`）、手工加一条、接受或拒绝。词库行同时是热词和已接受的显示替换。
- 内置术语仍是待定。本机模型只提议英文和术语，状态固定为待定，接受之后才进入 `lexicon.json`。
- 剪辑判断继续用原始 token。`06_phrases.py` 只改 `text`，`raw` 和 token 不动。
- 热词在 `01_transcribe_paraformer.py` 里交给下一次 Paraformer。
