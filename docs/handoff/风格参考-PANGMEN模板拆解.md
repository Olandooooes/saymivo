## 1. 最关键的结论：这是"两层"视频
**外层 = 冰纪用 Screen Studio 录了一个正在播放的视频**；**内层 = 被播放的那条视频本身**，是 AI 博主 **PANGMEN.AI（"旁门/胖们 AI"，画面水印 Pang men AI）** 的口播教程《怎么让 Codex "自生长"》，原片时长 **10:32**。

证据：
- 0:00–0:03 画面底部能看到播放器控制条（暂停键、`0:01 / 10:32`、音量、全屏图标），之后自动隐藏。
- 画面正中间始终停着一个**放大的 macOS 箭头光标**，整整 10 分半一动不动，是录屏的人把鼠标停在播放器上了。
- 所有剪辑上的动效（口播、字幕、花字、圆形人像、章节进度条、PPT、录屏、片尾广告）都在内层，是原作者剪的。

## 2. 内层视频的视觉系统（原作者）
1. **口播真人镜头**：紫色灯光背景、植物、白色笔记本、领夹麦。有两种景别交替：
   - 中景（人物在右侧，左侧留给大字标题，如 0:47 第一层卡片）

## 5. 给我们工作台的复现方案
目标：输入「口播原片 + 录屏 + 脚本/字幕」，自动输出这种"知识口播"成片。建议 **Remotion（React）做合成层**，FFmpeg 做预处理。

1. **预处理（FFmpeg + whisper）**
   - 口播：静音/口误/重复检测 → 跳切表（我们已有）。
   - faster-whisper 词级时间戳 → 字幕 SRT + 关键词。
   - 录屏如果是 Screen Studio/自己录的：导出鼠标点击日志（Screen Studio 工程里有光标数据；或者自己录时用 `cliclick`/系统事件记录），作为缩放驱动。
2. **LLM 生成"剪辑脚本 JSON"**：每一句字幕标注 `type`（talking_head / slide / screen / chapter_card / punch_text / cta）、`highlight_words`、`labels`、`chapter`、`pip_size`（small/large/none）、`zoom_target`。
3. **Remotion 组件库**（对应本片的每种元素）
   - `TalkingHead`：自动交替"中景/推近 1.35x + 暗角"，按句子跳切（`scale`/`translate` 用 spring 或者直接硬切）。
   - `PunchText`：黄色超粗字 + 黑描边 + 投影，spring 弹出（scale 0.8→1，80–120ms），支持多行逐行叠加。
   - `ChapterCard`：药丸 + 两行大字。
   - `ChapterProgressBar`：根据章节时间自动生成底部分段条，橙色进度线 = 当前帧 / 总帧。
   - `Subtitle`：灰底白字，按词级时间戳逐句显示。
   - `CirclePiP`：圆形人像，`small | large | hidden` 三态，用 spring 插值位置和尺寸。
   - `SlideDeck`：直接把 AI 生成的 HTML 幻灯片做成 React 组件（每页 build 步骤由时间轴驱动），比录浏览器更清晰。
   - `ScreenClip`：录屏片段，支持 ①平铺 ②3D 倾斜悬浮窗（CSS `perspective` + `rotateY(-12deg) rotateX(6deg)` + 白边圆角）放在品牌背景上 ③按点击日志的**自动缩放**（Screen Studio 风格：缩放到点击点附近 1.6–2x，ease-in-out cubic 约 0.6s，停留，再缩回）。
   - `Highlighter`：黄色半透明矩形从左往右擦出（clip-path inset 动画），坐标由 OCR（PaddleOCR）找到关键句所在框自动生成。
   - `Spotlight`：白色/黑色羽化遮罩聚焦某个区域。
   - `Label`：灰色药丸 + 黄字标签。
   - `OuterFrame`（可选）：壁纸 + padding + 圆角 + 阴影，复刻 Screen Studio 外包装。
4. **纯 FFmpeg 的轻量版**（不用 Remotion 时）
   - 自动缩放：根据点击日志生成 `zoompan`/`crop+scale` 表达式（`z='if(between(t,a,b),1+0.8*ease,1)'`，x/y 跟随点击点并做平滑），或者生成 `sendcmd` 关键帧。
   - 圆形 PiP：`geq` 或 `alphamerge` 圆形遮罩 + `overlay`，大小用 `scale` 的 `eval=frame` 做插值。
   - 花字/字幕：ASS 字幕（`\fscx \fscy \t()` 做弹出，`\bord \shad` 描边投影），`subtitles=` 烧录。
   - 进度条：`drawbox` 宽度 = `t/duration*W`。
   - 外框：壁纸 `overlay` + 圆角遮罩 + `boxblur` 阴影。
5. **建议优先级**：字幕 + 黄色花字 + 章节进度条 + 圆形 PiP 这四个做出来，就已经能复刻这个模板大约 70% 的观感；再加录屏自动缩放和荧光笔高亮，基本就是这一类知识口播的完整工作台。
