# 独立路径角色与闭合围栏

`path-runner.mjs` 与 `PathRunnerScene.tsx` 的两类实验机制已列入统一动效参数页的22项，并接入中央预览。原生组件仍返回 `canApply=false`、`uiAccepted=false`，本身不修改工程、时间轴或声音，不生成版本事实、规则或统计数据。统一参数页的最终应用使用独立的实际循环核验会话与不透明会话凭证（opaque receipt），不由这个原生标志直接授权。

两种机制分别配置：

- `closed-loop-runner`：作者给出连续闭合的三次 Bézier 段、每段秒数及明确圈数。持久阶段对象以稳定 `id/nodeId/segmentId` 对应源节点，角色进入相应段时激活；原有阶段卡始终保留。可选 `feedback` 只引用已有原节点，并指定出现秒数。
- `bounded-agent-runner`：黄矩形从右上出发，依次向下、向左、向上、向右描闭；规则标签只能在描闭后出现，角色随后出发。角色只沿显式 Bézier 段运行，重复运行要求原路径已经闭合。蓝点是确定性过去位置采样，有明确间隔、寿命和数量预算，不模拟碰撞、反弹、随机游走或成功率。

所有运动时点采用 `scene-source-relative-seconds` 和结构化 `startSec/endSec/durationSec`。Remotion 接口 `elapsed` 仍是完整原场相对毫秒；`binding` 另外保存原片绝对 `startMs/endMs`、本地 `src`、完整 SHA256 与原场 ID。原场整体挪时会失效。投影调用强制提供 `projectionProof={rawScene,clips,fps}`；模块先按绑定检查原始源场绝对起止，再重新投影并逐项比对当前投影、全部源内容和时钟。没有这条证明的投影片段拒绝预览，不能从同源路径、时长或零偏移推断绝对原点。测字几何缓存可跨保留实例复用，但不能代替该源时钟门。

完整 `title/body/node.text/detail/bullets`，以及已有 label/sourceNote/tags/links 和可选作者 annotation，均进入实际大字 `copyWindow`。该阅读窗口与图解分段；阶段/规则/反馈与角色名称也单独测量，不能只把正文存进库存。组件等待当前字体加载和全部真实测量，每一页分别按当前保留区间及速度计算完整曝光，最低 1.2 秒且不超过每秒 14 字素。少页、错文、最小字号溢出、被剪掉的第一页或变速后快闪均阻止全部图解；等待期间仍使用真实人物插槽。

每段全部控制点凸包加角色半宽高，保守包住角色及蓝点运动。该完整包络须在字幕上方，避开所有持久文字、真实人物插槽、人物全部关键帧总包络与手动保护区域；围栏还检查完整黄线描边。围栏内路径连控制点和角色尺寸都必须留在内部。保护门可能拒绝实际曲线没有经过的凸包空角，这是有意的保守限制，可通过调整显式控制点解决。

调用者必须传入 `speakerProof={kind:'same-source-video',src,sha256,startMs,endMs}` 与实际 `renderSpeaker`。证据必须与绑定完全一致；回调每次只调用一次，收到 `elapsed` 和 `sourceMs=binding.startMs+elapsed`。空输出、空 Fragment、只有空包装的输出会阻止图解并清理旧就绪状态。静态虚构人物不能用来宣称通过同源验证。该合同核对调用方证据，独立组件本身不重新计算视频 SHA，亦无法递归验证任意自定义组件内部真正解码了当前原片；统一中央链和参数页仍须核验可信原片解码、实际帧就绪与真实DOM，不能用空包装属性冒充验收。未知全幅脸位置始终 `needsFaceReview=true`。

已有截图、媒体或节点资产的场景会被拒绝，直到有支持它们的独立渲染安排，避免把证据素材悄悄省去。该实现的曲线、时长与蓝点预算为作者显式参数，不声称是参考视频的逐帧轨迹。尚未进行真实浏览器字体像素、人物边缘或成片观感验收。

统一参数页已提供结构化草稿、完整本场循环、快照失效检查和凭证应用/一次撤销通道；注册不等于这些路径在每个类型都实际通过。当前真实UI保存记录仅覆盖 emphasis、cumulative、ROI 三类，共8场；两类路径机制的参数编辑、真实人物/字体、完整循环与应用撤销仍待各自验收。

回归入口：`node --test tests/path-runner.test.mjs`。合成测试覆盖闭环/阶段/明确版本、围栏描边方向、规则顺序、无反弹、连续路径、人物与文字包络、源身份及相位、裁切变速逐页曝光、蓝点预算，以及实际 React 分支的等待/阻止/就绪状态重置和完整正文显示。合成测字不替代真实字体预览。
