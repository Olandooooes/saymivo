# 独立量化漏斗原语

`FunnelFlowScene` 已列入统一动效参数页的22项实验机制，并接入中央预览与凭证应用通道；它不自动写入工程。它根据作者明确提供的数量制作说明动画；粒子轨迹不是原始逐事件记录，不能充当真实系统录屏。注册不等于本类型已完成真实UI验收。

入口：

- `src/funnel-flow.mjs`：输入验证、带权点计划、源时钟纯状态、完整文字阅读检查。
- `src/funnel-flow.d.mts`：独立配置与状态类型。
- `src/FunnelFlowScene.tsx`：SVG 漏斗、灰色沉积、蓝色出口与累计、完整大字阅读窗口。
- `tests/funnel-flow.test.mjs`：合成回归，字体指标明确为合成数据。

## 数量与时间合同

必须显式提供 `totalCount`、`passedCount`、`unitPerDot`、`unit`、`dataKind` 和 `provenance`。数量是非负安全整数，通过数不得超过总数；每点权重为正整数。不从字幕猜值，没有数据就返回不可用。`dataKind` 区分有来源的事实数量和作者设定的说明数量，不在生产画面固定烧入开发角标。

每点保留整数重量，最后不足一整点的余数仍存在。一个入口点需要分流时，蓝/灰子点重量之和严格等于原点。末态包含余数碎点在内最多 512 点；超出时拒绝，要求作者明确调整每点单位，不偷偷改比例。点面积随重量变化，画面标尺使用 `1 点 ≈ …`。

每个源时刻满足：

```text
已发射 = 已过出口 + 已沉积 + 尚在途中
总数 = 已发射 + 未发射
```

蓝点真正到达图中出口后才加累计，再用 `collectMs` 进入底部蓝点区；灰点落定后才加沉积。不用“时间进度 × 最终通过数”冒充通过累计。统计比例仅由显式数量计算，全部运动结束后才显示。

`atMs`、`emitMs`、`inletMs`、`passMs`、`settleMs` 使用原场景相对源毫秒。`collectMs` 默认 350ms，仅为原创运动估算。曲线、点分布和布局也是原创估算，没有声称复刻参考的精确物理或曲线。相同源时刻求值稳定，回跳或乱序渲染不依赖上一帧。

## 完整文字与人物

本场有正文、节点文字、detail、bullets 或作者 annotation 时，必须提供 `copyWindow`。这个窗口在流动前或完成并停留后，用人物安全侧的整块区域以大字号完整分页；不把原文挤成图底小字。流动阶段仍显示完整标题、数值标签和单位。

组件等待实际展示字体加载，用真实宽高检查全部文字和最大数字框。任何文字放不进最小字号、与完整原文不一致，或某页在当前保留片段/变速后没有足够曝光，就报告 `blocked`。当前每页至少 1200ms、每秒最多 14 个字素是实验审阅门槛，不能替代实际阅读判断；跨多个片段合并曝光的证明尚未接入，不能勾选布局确认绕过缺页。

`renderSpeaker` 必须由调用方提供同一源时钟的真实本人画面。人物窗沿用保存的关键帧，图解区避让整个横向包络并留出字幕区。它使用圆窗，不需要人物 matte；静态头像不能代替本人。缺少该渲染入口直接返回不可用。

`onReadiness` 报告字体与布局的 `waiting/blocked/ready`，原生组件仍固定 `canApply=false`、`uiAccepted=false`，并要求人物预览复核。该标志不等于统一参数页的最终应用权限：后者需当前场景快照、实际完整循环与DOM核验的不可伪造会话凭证。几何与字体通过不能替代真实原声、素材身份或成片验收。

## 合成配置

下面数字仅供测试：

```js
const config = {
  kind: 'quantified-funnel-flow',
  dataKind: 'illustration',
  provenance: '原创合成例子',
  totalCount: 103,
  passedCount: 17,
  unitPerDot: 10,
  unit: '次',
  atMs: 7000,
  emitMs: 4000,
  inletMs: 1000,
  passMs: 1200,
  settleMs: 1000,
  copyWindow: {atMs: 0, durationMs: 6000},
};
```

场景须有足够源时长、完整文字、可行人物窗；配置本身不构成适配通过。调用 `funnelFlowIssues(scene, config, viewport)` 查看结构性不足，再通过真实字体渲染与 `onReadiness` 核对。统一参数页现已提供可编辑参数、预览快照失效检查、每个保留实例的核验会话及凭证应用/一次撤销通道；这些连接仍须在本类型的真实UI中逐项验收。

## 验证边界

回归覆盖非整除/分流重量、0 输入/0 通过/全部通过、真正出口时点、沉积、停止发射后的排空、随机访问同源时刻、剪口/变速源相位、横竖布局、人物窗包络、缺失数据拒绝、完整长文每页可见和字体/时间不足拒绝。当前真实UI保存记录仅覆盖 emphasis、cumulative、ROI 三类，共8场；本漏斗类型的真实字体像素、人物、完整动态循环、参数编辑与应用仍未验收，整片也未因此通过验收。

```sh
node --test tests/funnel-flow.test.mjs
npm run check
```
