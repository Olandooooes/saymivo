# 原句词语抽取与持久标签（独立实验）

`src/source-token-transfer.mjs`、类型声明及 `SourceTokenTransferScene.tsx` 已列入统一动效参数页的22项实验机制，并接入中央预览。它复制原句中的字/词到持久目标槽，原句、否定词、限定条件一直保留。不是截图 ROI，也不是整张资料卡飞行；不自动挑词、总结、翻译或生成语义标签。注册和显示草稿不等于本类型已完成真实UI验收。

## 可编辑合同

- `binding` 显式绑定原场 ID、原片 `src` 和完整原场源时长，`clock` 固定为 `scene-source-relative-ms`。投影裁切只改变真实曝光预算，不重置动画相位。
- `sources` 为本场每个原节点各保留一个稳定 ID。`expectedText` 必须逐字等于该节点的 `text`、`detail`、全部 `bullets` 以换行连接后的完整原文。节点改字后旧合同失效。`rect` 与 `atMs` 可编辑；原句出现后保持到原场结束。12 个原句上限是实验复杂度限制，不是建议把内容塞满。
- `tokens` 各有稳定 ID、原句 ID、原节点 ID、显式字素范围 `range:{start,end}`（结束不含）与完整同文 `text`。字素包含组合字符和 Emoji，不用 UTF-16 序号冒充字数。原节点、范围和文本三者不一致则拒绝。
- `targetRect`、`departAtMs`、`arriveAtMs`、两个归一化 Bézier 控制点可编辑。标签到达后保持到原场结束，其他已落槽标签仍保留。当前只接受单行完整词语；跨行或装不下时调整原句/目标框、选区或拆场，不截字。
- `copyWindow` 为完整标题、正文、可见标签、来源说明和关系标签安排独立大字时段；可完整分页，每页都要有真实保留/变速后的阅读停留。不能只勾选“看过”而漏显正文。已有媒体的场景当前拒绝此文字专用机制，避免切换后悄悄丢证据图。
- `protectedAreas` 可标记人物或其他保护区。源句、标签槽、整条曲线运动包络均不得碰已知人物窗全关键帧路径；保留底部 14% 给字幕。未知全幅人脸位置仍需真实预览，不能自动应用。

`sourceTokenTransferControls` 已作为统一参数页的结构化编辑字段合同使用。原句来源、字素范围和同文派生的具体编辑过程仍须在此类型的真实UI中逐项核验，不能从控件元数据存在推断整个选择流程已经验收。稳定 ID、绑定、原文和同文标签为只读派生字段，不开放任意改写的自由文本框。

## 实测锚点与完整内容

预览先加载当前字体，用 Canvas 的实测宽高排完整原句及目标标签。原句不可分页，否则其起点会在不同页跳变。随后以实际渲染的完整行创建 DOM `Range`，通过真实字框和舞台边界换算源位置，包含 Player 的 CSS 缩放。不会按字数估计横坐标，也不把缓存字体的旧字框用于新文字。

布局签名捕捉字体、视口、原场内容、节点、保护路径及全部配置，播放头变化不使它失效。DOM Range 不存在、跨行、多段字框、空尺寸、字体未完成、旧测量、完整长文放不下、运动超安全区或阅读不足，都等待或拒绝。飞出的同文从源字框开始，沿原创估计曲线移动，字号和框尺寸连续变到目标；原句始终留在原位。

原场相位按已有源时钟接口计算。每个保留投影分别核算源句、目标标签和正文页在实际变速下的曝光，不把被剪掉的页或飞行时间算成落槽阅读时间。当前单页最低 1000 毫秒、每字素 85 毫秒是保守实验参数，须结合实际口播与字量审阅，不能称为内容听审或通用质量指标。

## 验证范围

`node --test tests/source-token-transfer.test.mjs` 覆盖同文/条件、Emoji 与组合字符、UTF-16 DOM 选区桥接、曲线中态、精确完整运动包络、持久旧项、回跳、裁切变速、横竖画幅、长文各页真实曝光及过时测量。测试使用明确标注的合成测量和 DOM Range 适配输入，不能替代真实浏览器字体像素验证。

原生组件仍返回 `canApply=false`、`automaticAllowed=false`、`uiAccepted=false`，它本身不修改工程或原片。这不表示统一参数页没有应用入口：参数页通过独立的场景 draft、实际完整循环与DOM核验取得不透明会话凭证（opaque receipt）后，才能应用本场并支持一次撤销。原始场景 draft 另外绑定绝对源 `start/end`、原片身份 SHA、完整片段与当前内容，拒绝挪时或素材变更后的旧配置；本独立模块的 `id/src/duration` 不能单独证明绝对区间未变，不把成片投影起止时间当作源身份。

最新参考中观察到的抽词/持久记忆表达启发了此机制；参数和曲线为原创估计，不复制作者品牌，也不声称复刻其源帧或覆盖后续记忆检索、结果再利用。当前真实UI保存记录仅覆盖 emphasis、cumulative、ROI 三类，共8场；本类型的真实字体/标签起点像素、完整循环、人物避让、结构化编辑与应用撤销仍待逐场验收，整片也未因此通过验收。
