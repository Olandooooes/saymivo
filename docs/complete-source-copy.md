# 九类独立动效的完整全文窗口

`DynamicMechanismScene` 是九类机制的完整内容入口，已在统一动效参数页与中央预览中使用。底层 `FlipBoardScene` 等叶子只负责原生动作，直接调用不能代表完整内容已显示。`SourceCopyWindow` 在原场关键动作前，实际绘制完整 `title`、`body` 和每个节点的 `text/detail/bullets`，包括没有被条形、ROI 或 Hub membership 引用的节点。它不使用调用方提供的 `displayedFields`，也不把隐藏 DOM 中存在某句话当作可见证据。

## 显式配置

每个现有配置可附加：

```ts
sourceCopyWindow: {
  atMs: 0,
  endMs: 12000,
  rect: {x: .05, y: .10, width: .65, height: .62},
  speakerRect: {x: .79, y: .48, width: .14, height: .24}
}
```

这是合成形状示例，不是新任务的默认时点。内容与字量由渲染器从当前场景生成，不能通过填写字段 ID 自报完整。原句不做摘要、不删除重复字段、不忽略否定与条件。窗口使用当前已加载字体实测完整宽高，字号下限为输出高度的 3.2%，不足时完整分页；英文单词保护为整词，不改变空格与文本。每页需满足当前实际保留区间和变速后的阅读预算。放不下或读不完则拒绝，不改成固定小字 footer。

## 时序

窗口、原动作都使用完整源场的相对毫秒。已有 `elapsed` 原样传给原生组件，没有减去说明时长，没有改源时间，也不会自动压缩动作。

- 翻字板实际首次填格、计数的实际起点、玻璃胶囊各节点入场/组退场、条形各行入场都纳入冲突检查。
- 证据接力检查实际默认或显式 cue、人物/背景交接；圈点检查聚集、开口、转移。两者的原媒体摄像机、光标、标记及从源零开始播放的视频也纳入。会动的视频不能假装成静态总览，在全文窗期间悄悄跳过前部。
- Hub 检查真实图解显现、输入/中心出生、分支、输出、点流、门控、重排和引用时点。没有延后图解显现的默认 Hub 从源零开始，因而没有可用前置空档；需明确改时点或拆场。
- ROI 检查放大、说明行和高亮；双语检查每个实际 pair 的换面时点。
- 证据、圈点、ROI 和双语还需在全文窗之后留出 1000 毫秒干净总览。这是保守实验准备时长，不冒充参考片的精确参数。

前置窗口结束前旧图形保持隐藏；窗口结束后按原来的源相位显示，关键动作不被遮掉。空档不足就 `blocked`，没有自动移动 cue、重定时或修改工程。真实人物窗在同时发生的保存关键帧路径内与正文避让；不把说明结束后的未来人物位置误算为同时碰撞。

## 字体与真人

在全文字体/页面和全部原生字体布局就绪前不放行旧图形。现有 `useMeasuredText`、`useStableGlyphLayout` 通过 `TextLayoutReportContext` 回报实际加载后测量；内部按九类实际 hook 路径与相位签名等待全部报告，任何 `unplaceable` 拒绝。合成回归对照实际渲染调用数量，不能用外部勾选跳过。该计数只证明字体布局已返回，全文可见性仍由独立窗口实际逐页绘制保证。

图形可见性与真人层分开。Evidence 的 live 背景/真人回调、Hub 的 live 背景/抠像回调不一起隐藏；其他类在说明时段要求 `renderSpeaker` 回调与安全人物框。回调存在不等于实际原片身份、RGBA 覆盖或人脸像素已经验收，未知脸位置仍须真实预览。该层不改主轨声音，原片和音频由现有调用方持续播放。

## 当前边界

- 九类已包含在统一参数页的22项实验机制中。原生入口的 `canApply=false`、`uiAccepted=false` 表示组件不能自行写工程；统一参数页另以实际完整循环和DOM核验取得不透明会话凭证（opaque receipt），再完成本场应用/一次撤销。旧配置没有完整窗口仍会明确拒绝，不会静默导出漏字版本。
- 单个组件只知道当前投影；跨剪口源场的后半投影如果没有前置全文页，会保守拒绝。中央场景合同已从真实 raw scene、完整clips和原片身份绑定当前预览，并审核每个保留实例；这不允许把不存在的前页算作已经读过，也不自动合并不同投影的阅读曝光。
- 字体测量成功不能替代图片解码、原片身份、真实抠像、完整原速播放或成片观感。当前真实UI保存记录仅覆盖 emphasis、cumulative、ROI 三类，共8场；这九类中只有ROI包含在该记录内，不能据此宣称其余八类或所有复杂布局都已验收。

回归：`node --test tests/complete-source-copy.test.mjs`。覆盖九类真正入口、正文/未映射节点、英文空格和否定、横竖多页的实际可见页面、真实 hook 路径计数、等待/过时/放不下时不闪旧图、真人保留和源相位不重置。测量为明确标注的合成字体，不能称为真实字体像素检查。原来的叶子动作/分页测试继续独立验证原语，并不代表通过全文入口。
## 原生测量生命周期

原生文字回报按已挂载 hook 的稳定实例 ID 更新，卸载或文字／尺寸变化时撤回旧回报。同一布局反复 effect 不能冒充多个已测对象；两个真实独立但同文的对象仍分别登记。完整内容／配置／尺寸／字体变化会清空旧来源快照，当前节点或指标阶段由实际挂载／卸载回报更新，不用每个动画相位重置全局测量身份。

`speakerRenderedExternally` 默认 false。中央入口已全场保持真人时可设 true，只去掉全文窗的 fallback 人物重复层，仍要求有效 callback，Evidence/Hub 原生人物交接不受影响。

`tests/native-layout-lifecycle.test.mjs` 用明确合成 Canvas 度量执行真实测字 hook 的异步 effect 和 cleanup，持续切换 Orbit 节点、Hub 指标出生与回跳。它验证实际状态能收敛、回报数量准确、连续帧不因计数值重测、旧布局不可替代新长文；不代替真实浏览器像素验收。
