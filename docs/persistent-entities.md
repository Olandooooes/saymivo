# 持久对象与状态

动效参数页新增一个“持久对象与状态”入口。两个可选参数组使用同一个时间线 reducer 和 renderer：真实图片逐个入栈后整组附着；五条任务按明确示意时点完成，保留全部成员的摘要再归档。两个参数组可以同时添加。

图片只能绑定本场现有节点的真实图片；原文和 SHA、尺寸均由当前节点与本地素材取证派生。任务、摘要与完成时点属于作者明确提供的原创示意，不代表任何软件真实执行。原场全文、任务条件和摘要成员快照保留，不能靠隐藏待办把摘要变为全部完成。

参数使用原场相对秒。全文窗口必须先于原生动作；每张原图需有完整独立阅读，缩略图不强塞小字。实际字体逐页测量、保留剪口与倍速阅读、图片解码以及整组运动包络均参与核验。两组组合目前要求完整历史运动包络空间分离，暂不支持附着后复用腾空区域。

原生 `canApply=false` 表示该组件不能自行修改工程。实际应用沿现有完整循环、DOM 字体/原文/真实素材/真人核验和人工审阅生成的 opaque receipt，再执行一次可撤销保存。缺字段、丢图、失配、阅读时间不足或人物字幕冲突会阻断；不能手写签名绕过。

入口、纯状态和组件回归已接通；真实工作台编辑、完整循环、应用/撤销/重做及最终导出像素仍待独立项目验收，不能据测试称全库可用。组件不新增音轨或人物视频，不修改原声、剪口或本场原文。

回归：`node --test tests/persistent-entities.test.mjs tests/persistent-motion.test.mjs`。
