# 倍速导出

播放器下方的「预览倍速」只改变试听速度。顶部「导出倍速」决定下载的 MP4，支持 0.5、0.75、1、1.25、1.5、2 倍；正式导出和预览导出均使用此设置。它是本次导出选项，重新打开工程时恢复 1 倍，不修改已保存剪口或片段速度。

导出先按工程完成字幕、动效和原声音频同步收尾，再对完整成片统一变速。视频使用 `setpts`，音频使用保持音高的 `atempo`，从而避免字幕和动效仍按原速而声音已加速。1 倍直接保留原导出链。倍速处理成功前不提供完成下载链接；失败保留原速文件供检查。播放器预览静音不影响导出音轨。

验证：`tests/export-speed.test.mjs` 校验速率白名单与原速直通；实际成片应检查时长约等于原速时长除以导出倍速，并检查视频和音轨时长。数值检查不能代替试听。
