# 字段与字形滚动看板

独立基础模块位于 [field-roll-board](../src/field-roll-board.mjs) 和 [FieldRollBoardScene](../src/FieldRollBoardScene.tsx)。尚未注册到动效库，也未接入保存、撤销或导出；不表示已有真实 UI 验收。

参考依据是官方[第77集](https://www.douyin.com/video/7699453390744489226)约02:22–02:26、02:30–02:35：卡片保持身份，类别、语言等字段先后出现过渡字符，最终稳定为完整目标值。现有 `BilingualBoardScene` 旋转整张卡的正反面，不能代替字段内部的滚动。观察没有确认三维翻轴、逐源帧边界或原缓动；过渡中的其他语言代码也不能当成翻译事实。

首版支持同一稳定卡片内多个字段。每个字段显式保存原文字段引用、完整旧值、新值、标签、矩形、映射来源和原片时点。字素分别沿纵向滑入、滑出自己的遮罩，卡片本身不翻面。较短值以空槽配对，不切开组合字符、Emoji 或英文空格；中间态只含所供旧/新字形，不生成随机数字、执行计数或翻译。平台图标和资料素材尚未接入；原场已有资料时明确阻止该文字机制，避免静默丢图。

原值和目标值分别拥有完整阅读停留，卡片入退及滚动时间不计为可读时间。保留实例、裁切、倍速按原片时钟核算；后退 seek 不继承未来状态。所有完整源标题、正文、节点、附加条件、标签与关系说明先在正文窗口中保留。

组件等待当前字体加载后用真实 Canvas 测量所有字素的 advance、左右墨迹界、上升和下降部，按整个字段的最大字格固定布局。缺测量、源字段不符、字格装不下、阅读窗太短或当前投影不符时拒绝就绪。实际字幕清单和剪辑实例必须显式传入，字幕停留的画面保护带、人物全部窗关键帧的包络以及附加保护区共同参与几何检查。

父级接入仍须提供：

- 当前源身份、完整 `projectionProof={rawScene, clips, fps, captions}`，以及匹配绑定的真实人物槽。
- 字段引用、只读原值、可编辑目标值、来源说明、独立时点与矩形控件。
- 当前实际媒体解码和 DOM 字形可见性检查；原生字体/几何就绪不代替这些证据。
- 完整循环、当前草稿凭证、保存后读回、一次撤销和实际导出核验。保留原片唯一音轨；此组件不创建音频或人物视频。

定向回归：

```sh
node --test tests/field-roll-board.test.mjs
```

测试用原创合成文字与显式合成字体度量，覆盖双方向字素滚动、完整字量、过时字体、异步字体完成、入退停留、裁切变速、重复实例、实际字幕保护带、人物包络和 JSX 遮罩。测试不代表实际字体像素、真人边缘、完整循环观感或 UI 应用已通过。
