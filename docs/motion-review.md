# 动效逐项播放与原片对照

入口是本机工作台的 `/motion-review`。首页左侧的“动效逐项验收”和编辑器动效库中的链接都会打开独立页面，保留当前编辑界面。

## 怎样使用

1. 从目录或顶部下拉框选择一项。切换后两边保持暂停，避免旧片段在后台继续播放。
2. 点击“同时重播”，观看现有组件和对应真实原片。也可以分别播放、循环、慢放，或放大其中一边。
3. 参考存在多个不连续时段时，用“对应片段”切换。每个本地短片都从0秒播放，下面另标其在原视频中的起止时间。
4. 阅读“与参考还差什么”和具体未完成项。已有配置、可播放和参考等价是不同状态。
5. 写备注，选择“通过本项”“需要返工”或“保持待验收”。结论只存在本机浏览器，不保存、应用或修改口播工程。

两边使用各自的时长和动作节奏。“同时重播”意味着同时从各自起点观看，不保证逐帧相位相同。示例中的真人原声与原创说明文字没有语义对应，默认静音；它们用于观察当前组件，不是新剪好的口播。

## 状态怎样解释

| 状态 | 含义 |
|---|---|
| 未完成 | 当前示例缺少可执行条件或实际播放受阻；页面保留原因和参考 |
| 部分完成 待验收 | 有可播放示例，但没有得到用户对效果的认可；差异继续显示 |
| 需要返工 | 用户明确记录了返工要求；不会因为播放成功而自动消失 |
| 已完成 你已通过 | 用户对当前示例和参考明确点击通过，且身份仍与验收时一致 |

示例、配置、素材身份、参考SHA或范围、差异说明改变后，旧通过失效，备注保留。参考视频播放器按SHA和范围重新建立，避免新身份继续使用旧解码画面。

技术就绪回报只说明当前实际帧的组件、字体和来源状态。页面不会生成工程应用凭证，不会把当前帧就绪当成完整动效或成片通过。

## 当前本地检查范围

2026年10月23日这轮检查中，32项均已对应真实原视频短片。30项原创示例逐项启动，实际播放器帧有推进；2项仍明确未完成：分支流示例的前置阅读与原生启动时序冲突，音频A/B尚缺通过真实同步和完整覆盖的实例。

另检查了两边默认静音、切换后暂停、共同慢放、统一暂停、多参考片段从0秒起播，以及临时反馈保存、重开和清理。逐项启动检查不是30项动作全过程的审美认可；用户通过数保持独立，不由这些检查增加。

本次参考文件仅保存在本机被Git忽略的目录，不随源码分发，也不上传作者视频。其他机器没有相应素材时，页面会显示缺项。私人检查截图和操作结果留在本机证据目录，不用作公开仓库示例。
