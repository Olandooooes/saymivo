# 中性复现夹具

用虚构的「示例主题 / 示例重点 / 窗口线稿 / PIP 占位圆」演示：独立图层叠加、圆窗几何、以及可编辑 ASS 样式。**不是真实口播产品，不是已认可素材库，也未声称测试已经跑过或通过。**

- `picture_compositor.py`：可迁移的合成函数（由历史渲染脚本抽取，已去掉私有口播、身份路径与时间线）。
- `fixtures/`：中性 PNG。`preview-key-state.png` 是按示例数据合成的一帧，供工程对照，不是审片通过证明。
- 字幕样式在 `../05-风格配置/caption-style.example.ass`，文本为虚构例句。

在已安装 Pillow、NumPy 的环境可将本目录作为 `{FIXTURE_DIR}` 做合成试验。不要把本夹具扩写成全片渲染。
