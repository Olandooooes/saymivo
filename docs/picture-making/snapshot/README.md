# 附件快照

本目录保存本轮云附件里的清单、任务书和字体说明原件，便于对照哈希。它们不是第二套开工规则。

- 开工读 [制作包入口](../README.md)，再读 [项目配置](../project-config.md)。
- `云任务说明.md` 是当时发给云代理的任务书，不是给后续 Codex 的现行指令。现行实测步骤在 [CODEX-实测接续.md](../CODEX-实测接续.md)。
- `仓库更新后给Codex的测试指令.template.md` 是附件里的模板。它还没有本分支和提交号。不要按那份模板从 `main` 开工。
- `FONT-LICENSE-AND-SOURCE.attachment.md` 是附件原文：附件本身不带字体二进制。仓库是否分发字体，以 [fonts/FONT-LICENSE-AND-SOURCE.md](../style/fonts/FONT-LICENSE-AND-SOURCE.md) 为准。
