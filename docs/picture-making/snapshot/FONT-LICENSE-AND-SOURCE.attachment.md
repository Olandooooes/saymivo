# 字幕字体：许可与可获得来源

实际已用字体家族：**Noto Sans SC**，字重 Bold（libass 选择 `NotoSansSC-Bold`）。同一字体目录中也曾放入 Regular 与可变字体文件，烧录时选中的是 Bold。

许可：SIL Open Font License 1.1。许可文本：https://openfontlicense.org  
家族页面：https://fonts.google.com/specimen/Noto+Sans+SC

本附件**不打包字体二进制**（体积大，且仓库侧应使用合法获得的文件）。云代理或后续工程应自行按上述来源获取，并在项目中保留 OFL 文本与来源说明。获取后的建议文件名：`NotoSansSC-Bold.ttf`（必要），可选 Regular。

不要把某期字幕样式写进通用 skill 当作所有项目的默认字体；字体与字号留在项目配置（见同目录 JSON / ASS 示例）。
