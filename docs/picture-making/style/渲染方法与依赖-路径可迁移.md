# 渲染方法、依赖与路径迁移

## 方法（来自已用技术，已去掉私有时间线与口播）

- 画布 1920×1080、30 fps；图层按独立 PNG 叠加（背景、示意/界面、解释字、圆窗、白环）。
- 透明度用平滑 fade；对象按语义保持，交接可用短交叉淡化，但须实审，不能用程序自证。
- 字幕用 libass 烧录或保留可编辑 ASS；样式见 `caption-style.example.ass`。fontsdir 只放字体文件，不要把 fonts.conf 放进 fontsdir。
- 常见依赖：Python 3、Pillow、NumPy、ffmpeg（libx264、libass）。音频若复制原轨用 AAC copy；本夹具不附原音。

## 路径

- 不要在仓库脚本里写死 `/workspace/...` 或本机用户目录。用相对仓库根目录的路径，或环境变量（如 `SAYMIVO_FONTDIR`、`SAYMIVO_PROJECT_CONFIG`）。
- 本附件脚本中的占位符：`{PROJECT_ROOT}`、`{FONTDIR}`、`{FIXTURE_DIR}`。
- 历史制作脚本曾使用绝对工作区路径，那些原件留在项目本地，不作为可运行的公共脚本复制。

## 本附件不包含

私人界面、人像帧、原音、Notion 稿、真实口播 SRT/逐字稿、已锁定成片 MP4。
