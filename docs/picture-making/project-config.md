## 私有主档不在仓库时怎么开工

技能第 9 节、第 10 节和开工检查第 1 条都要求：从项目交接或配置定位唯一主档，重读最新全文；定位或读取失败就说明缺口并停止。清单第 45 条同样要求重读，并写明无共享路径时可以核读用户提供的最新副本。

只克隆本公开仓库时，私有《口播视觉制作错题本》CHARTER-v1.13 没有路径可读。若仍把「去打开那份 box 文件」当成唯一定位，开工检查会停在一个仓库里不存在的文件上。本配置把这处依赖改成下面的可执行规则。技能和清单原文不改。

1. **本配置就是定位页。** 只持有本仓库时，用户已批准放入仓库的最新可读副本是：公开执行清单（64 条 + t92 流程 + t94 字幕 + t99 布局 + t127 记录，条目未删）加上两份技能原文。开工检查要求重读的「最新全文」，在这个检出里就是这些文件的全文，不是会话摘要。
2. **私有全文记为缺项，不因此停工。** 停工条件是：上面的公开快照读不到，或 `SAYMIVO_PRIVATE_CHARTER` 已设置但文件打不开、或 SHA256 不是 `ad691aa296b45ec85cca832c5b8b524e14ebcf914ea8bcd57c3723c323efd5a7`。哈希不符时停止并报告，不要改用别的文件冒充 CHARTER-v1.13。
3. **设置了且哈希相符时，改读那份全文。** 私有全文效力高于公开清单。公开清单不替代它，也不是第二权威正文。
4. **清单里没有写出的主档句子，不要编。** 公开清单已经保留的条款可以执行。主档里可能还有未脱敏进清单的句子，那些句子不在仓库里，不能靠记忆补上。
5. **三处相对链接已有落点，落点不是原文。** [口播视觉制作错题本.md](rules/口播视觉制作错题本.md)、[阅读指南.md](rules/阅读指南.md)、[history/t86-执行清单接线核验.md](rules/history/t86-执行清单接线核验.md) 只说明缺什么。读落点页不等于读过清单或读过私有全文。t86 核验记录原文不在仓库。
6. **P-01 重读频率仍未裁定。** 未裁定不等于可以不读。每次开工仍重读两份技能全文和清单里本轮适用的部分。

效力顺序不变：用户最新明确原话（仅其明确范围）＞ 主档现行条款（有匹配哈希的私有全文时用全文；否则用公开清单里已写下的条款，并注明私有全文缺项）＞ 本次构图合同与本配置里的样式 ＞ 未被取代的技能与 SOP ＞ 历史。清单和专题没有独立裁定权。助理承诺、摘要或自动审片不是用户授权。

## 哪些是通用，哪些不是

分类以 [效力与来源映射.md](rules/效力与来源映射.md) 为准，这里只复述边界：

- **通用：** 清单第 1–52 条、第 62 条，t92 / t94 / t99 里写明的通用部分，技能第 1–12 节。
- **项目限定：** 清单第 53–61 条、第 63–64 条里「本片 / 指定参考」的限制；R-36、R-52、R-59 中不得把某片参数升成跨项目默认的部分。左上话题字号的本片折中只约束该片。
- **历史：** 清单文首和各轮「当时制作 / 当时认可 / 当时基线」的叙述，以及被否定的旧静态方向。历史留着，不是当前样式已经通过的证明。
- **待定：** 未听校的口播时间、参考逐帧实测、未授权公开的素材库、未确认的跨项目字体或像素阈值、P-01。待定不能升成通用默认，也不能写成已通过。

[style/camera-and-caption.example.json](style/camera-and-caption.example.json) 里的圆窗（圆心 224.5, 854.5，外径 377，环宽 14）和字幕（Noto Sans SC 64、白 / `#F4DA60`、BorderStyle 3、Outline 10、`an2`、`pos 1180,1038`）是某一项目已确认的示例。动画验收要求里的「左下真人圆窗」与这组几何同属该项目示例。它们不是所有新片的默认像素。252px、378px 仍只限清单里写明的旧样例。

## 中性渲染入口

技术核验和中性预览：

```bash
python3 scripts/picture-making/verify-package.py
python3 scripts/picture-making/render-neutral-preview.py
```

依赖是 Python 3、Pillow、NumPy，以及带 libass 和 libx264 的 FFmpeg。字体文件见上一节。命令退出码 0 只表示文件、链接、字体命中和夹具像素能重建。它不是审美通过。没有播放成片就写「未看视频」「未听」。

当期口播的最小样片步骤在 [CODEX-实测接续.md](CODEX-实测接续.md)。本配置不授权全片或发布。
