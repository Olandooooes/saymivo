# 口播制作错题本开工检查

1. 从当前项目交接或配置定位唯一错题本主档。重新读最新全文，不能用会话摘要、记忆或旧版代替；无法定位或读取时，先说明缺口，不继续制作。不新建平行正文。
2. 同时读取本轮适用的制作技能、SOP、指定参考拆解与验收要求。区分跨项目规则和本项目限定。
3. 先确定段落希望观众记住的主题与核心判断，再设计主题字、解释素材、细节文字三级层级。大字号和少量语义配色突出核心判断；局部关键词强调不能代替主题层级。真实稿件先核对来源，不擅改口播。
4. 素材与动效服务主题，主题建立后由解释材料有主次接力。局部解释可短时接过焦点，不机械保持大标题压过一切，不全层同时动、不为变化次数加动作。
5. 按错题本最新确认关卡执行；静帧认可、动态通过、用户审美确认分别记录，未通过不擅自推进。交接时给权威路径、版本、适用条款、未批准项，接手者自行重读。
6. 错题本只追加，保留原文；重复或冲突标注关联，不自动合并覆盖删除。删除任何旧条必须列出具体条目和理由，先获用户人工确认。记录读取版本、落实条款和当前关卡；项目路径留项目交接，不把私有资料复制进本通用技能。
7. 从项目阅读指南、交接或配置定位同一主档的派生精简执行清单，并在开工与交付前按本轮范围逐项核对。精简只压缩措辞，不删要求：清单须有来源映射，通用要求、项目限定、历史记录与未决项分开，最新用户纠正单独承接；清单不替代主档全文，不成为第二权威正文，同一要求不重复执行。按最新明确用户原话、主档现行规则、构图合同、未被取代的技能与SOP及历史处理冲突，同级不明列待确认且不扩大推进；不得自行把项目参数或未决项升成通用默认。内部记录每项适用要求的实际做法、证据、状态、范围与未决，不适用写具体理由；不让用户填表，不以无关空表阻断，不以勾选、代码存在、静帧或技术通过冒充实际完成及审美认可。清单缺失或覆盖不全时如实补齐来源，不把预备入口说成完整规则已落地。
